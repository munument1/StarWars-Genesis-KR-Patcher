# Genesis 8.8.4 Strings 번역 반영·검수 상태

이번 8.8.4 호환 작업은 **패처의 지원 버전과 설치 파일 무결성**을 갱신하는 작업입니다. 원본 게임/모드팩의 새로운 모든 문구를 완역했다는 뜻은 아닙니다.

## 변경 감지

8.8.32용 번역 레시피에서 해당 Strings가 없던 8.8.4 신규 ID는 **3,707건**, 원문이 달라진 기존 ID는 **1,008건**입니다. 이 두 값은 *Strings 파일의 위치 수*이며, 고유 영어 문장 수나 실제 게임에서 읽을 수 있는 문구 수와는 다릅니다.

| 분류 | 8.8.4 Strings 위치 수 |
|---|---:|
| 신규 ID 및 원문 변경 | 4,715 |
| 동일 원문과 유일한 한국어 번역을 확인하여 재활용 | 295 |
| 현상금 길드 대사·퀘스트 일지·변경 대사 추가 한국어 번역 | 629 |
| UI·장비·명칭·유우잔 봉 언어 음역 등 추가 검토 번역 | 505 |
| **한국어 반영 총계** | **1,429** |
| 빈 원문, 공백/개행 전용 | 640 |
| 독립 실행시간 변수·토큰 | 261 |
| 모델/메쉬·스크립트·디버그 등 기술 내부용 | 1,511 |
| 표시 여부나 의미가 불명확해 보류 | 874 |

신규·변경 문자열 중에는 디버깅, 얼굴/머리카락 메쉬, 엔진 식별자, 런타임 `<Alias=...>` 토큰과 같이 **번역하면 안 되는 항목**이 포함됩니다. 따라서 '아직 한국어를 적용하지 않은 위치'를 그대로 '미번역 화면 문구'로 해석하면 안 됩니다. 반대로 추출기가 모든 표시 문구를 포착했다고도 보장할 수 없습니다.

일례로 `starfield_en.strings` 안에서 한국어 재사용 번역을 찾지 못한 2,751건을 보수적으로 분류한 결과, 모델·엔진·개발용 식별자 1,511건, 변수 태그 단독 248건, 빈 문자열 39건이 구별되었습니다. **나머지 953건은 화면용일 가능성을 배제할 수 없어 사람 검토 대상으로 유지**했습니다. 이 수치는 문맥 없는 자동 분류 결과이며 완역/검수 확정 수치가 아닙니다.

최종 2차 확인에서 모든 953건을 다시 검토해 가능한 항목을 번역했습니다. **유우잔 봉 외계어 74개 위치는 공식 의미가 확인되지 않아 뜻을 만들어내지 않고 한글 발음만 옮겼습니다.** 현재 보류 874건에는 실제 게임 내 표시 여부를 확인할 필요가 있는 소수의 명칭도 포함되어 있습니다. 자세한 ID/영어/한국어/보류 이유는 로컬 작업 공간 `Strings_8.8.4_completion/final_coverage_records.csv`와 `final_coverage_report.json`에 남겨 두었습니다.

## 번역 방식

- 기존 파일에서 **문자열 ID와 영어 원문이 모두 일치할 때만** 기존 번역을 재사용합니다.
- 변경된 원문에는 해당 8.8.4 영어 내용에 맞는 새 번역을 별도로 작성합니다.
- 번역의 `<Alias>`, `<Global>`, `%` 변수·개행 수는 검사합니다. 사람이 읽는 대괄호 선택지는 번역하지만 시스템 버튼 토큰은 보존합니다.
- 엔진 식별자·모델 번호·기술 문자열, 번역 충돌 항목은 원문을 유지합니다.
- 버전/원본 입력 해시가 일치하지 않으면 패처가 적용을 중단합니다.

## 완료한 검증과 남은 검증

원본 Genesis 8.8.4 구성의 격리된 MO2 샌드박스에서 패처 **183개 작업 생성·적용·복원**을 시험했고 파일 159개가 원래 SHA-256으로 복원되는 것을 확인했습니다. 게임에 설치한 실제 사용자 원본은 변경하지 않았습니다.

추가 번역은 기계적으로 ID·원문·태그/변수를 검증했으며, 전체 8.8.4 인게임 플레이와 대사 말투의 사람 교열은 완료되지 않았습니다. 새 원문과 기존 번역이 충돌하는 78건도 임의 자동 수정하지 않았습니다.

이 때문에 안정 정식 릴리즈 전에 게임 내 검수를 계속해야 하며, 패처에는 릴리즈 후보 상태를 표기합니다.
