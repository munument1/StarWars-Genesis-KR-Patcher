# Genesis 8.8.41 한국어 번역 및 HUD 변경 검수 현황

2026-11-01 기준 8.8.4 원본과 8.8.41 설치본을 파일 SHA, 레코드/원문, MO2 선택 우선순위로 비교했습니다. 원본 게임과 MO2 프로필은 읽기만 했습니다.

유우잔 봉 모드의 마스터 순서가 바뀌면서 새 레코드처럼 보였던 79개 필드는 동일 원문으로 재인덱싱한 것이며 신규 번역 143건에 포함하지 않았습니다. 번역 사전에서 원문과 목적문이 유일하게 일치한 83건과 새로 검토한 104건을 적용했습니다.

변경 ESM에서 기존 번역의 안전 재사용을 위해 실제 레코드 원본을 비교했습니다. FD/FE 식별자 자체를 무조건 재사용하지 않으며, 동일 파일·레코드·필드·영어 원문에 더해 원본 본문 또는 EDID를 확인해 매칭했습니다. 유우잔 봉 INFO 52건은 원본 레코드가 바뀌었고 EDID도 없어 확실한 연결이 불가능하므로, 2개 방어구 레코드와 함께 보수적으로 보류했습니다.

신규 HUD `Star Wars - HUD Overhaul/interface/playerhudcomponents.gfx`의 내장 FontID 2400에 한글 11,225자와 크기·간격 조정 태그를 합쳤습니다. 원본 영문 글리프와 그 외 2,585개 SWF/GFX 태그는 변경하지 않습니다. 새 8.8.41 입력 해시가 정확히 일치할 때만 이를 생성하도록 제한합니다.

### HUD 인게임 검증 보고 (2026-11-01)

- **확인자:** 패치 사용자 직접 실행 및 피드백.
- **확인 결과:** Genesis 8.8.41에 적용한 새 HUD에서 **한글 정상 출력**, **글자 잘림 없음**.
- **검증 범위:** 해당 사용자가 확인한 실제 HUD 표시. 테스트 해상도·UI 배율·전체 방문 지역/모든 HUD 상태의 상세 목록은 제공되지 않았습니다.
- **여전히 남은 범위:** 스캐너·은하 지도·Power HUD·대사·장비 등 UI 전수 검사, 다른 환경 호환성, 퀘스트 및 번역 문맥 확인. 새로운 UI 파일이나 PEX/BA2에 실사용 문자열이 추가돼 있을 가능성도 있습니다.

### 대화 자막의 화자 표시명 영어 출력 (2026-11-01)

- **증상:** NPC에 **커서를 갖다 대면 `우주항 운영자`로 한국어 표시**되지만, **대화 자막 앞에 붙는 화자 표시명**이 영어(`Space Engineer`)로 나타납니다. **대사 내용 자체가 영어라는 제보가 아닙니다.**
- **사용자 확인:** 위 문제를 제외하고 확인한 다른 한국어 표시와 HUD는 정상입니다. 이는 전체 대사의 전수검사를 뜻하지 않습니다.
- **원인 상태:** 8.8.41 모드의 ESM 224개 및 외부 번역 문자열과 Starfield 기본 영문 로컬라이제이션 BA2를 읽기 전용 검사했으나 `Space Engineer`라는 독립 문구의 위치가 확인되지 않았습니다. 대화 UI 화자 표시명은 일반 커서 표시명과 다른 경로(대사 화자 별칭, 짧은 이름, 추가 데이터)일 수 있으나 현재는 미확정입니다.
- **다음 수정에 필요한 정보:** 영어 화자명이 보이는 대화 화면 또는 관련 화자의 정확한 레코드·플러그인 정보. **정상인 커서 표시명이나 대사 본문을 임의로 바꾸지 않습니다.**
- **추적:** [이슈 #9 — 우주항 운영자 대화 화자 표시명이 영어](https://github.com/munument1/StarWars-Genesis-KR-Patcher/issues/9)

`8.8.4` 정식 패처에서 확인한 압축 방식 차이 오류 대응, 무결성 검사, 백업과 복원 기능은 유지합니다. 기존 8.8.4용 정식 배포와 8.8.41 릴리스 후보를 혼동하지 마세요.
